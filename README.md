### 🚀 Featured Engineering Project

#### [AeroDispatch — Cloud-Native Logistics & Telemetry Engine](https://github.com/AnilPrajapati543543/aero-dispatch)
> **Enterprise-grade multi-modal logistics dispatch, real-time GPS telemetry, and driver allocation platform.**
- 🌐 **Live Web Application:** [AeroDispatch Production](http://aerodispatch-web-761112473042.s3-website.ap-northeast-2.amazonaws.com)
- ⚙️ **Cloud Architecture:** AWS Elastic Beanstalk (Python 3.12 / FastAPI), DynamoDB Single-Table Design, AWS Cognito Auth, S3 Proof-of-Delivery, and React 19 SPA.
- ⚡ **Key Features:** Live AWB telemetry tracker, dispatch assignment with scroll isolation, WhatsApp-grade profile avatar viewer with AI background removal, and multi-tenant role-based access control.
